# Support

Contact the ZyGen support team through [ServiceDesk](https://zgbackoffice.atlassian.net/servicedesk/customer/portals) for project setup, repository migration, access requests, or technical assistance.

Include the project name, a brief description of your request, and the relevant repository URL where appropriate. Do not include credentials, personal data, or confidential information that is not needed to handle the request.

For project-specific setup and usage, start with the project's README and documentation.
