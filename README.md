## Default files

GitHub can use supported community files from this repository when a project does not define its own. Project-specific instructions take precedence. Default files are not copied into project clones.

Workflows and access controls must be configured for each project; this repository does not enable them automatically. See [GitHub default community files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## Maintaining this repository

Keep content suitable for public access. Check links and image references before submitting changes. Publish only information approved for external use.
